# External Math Reproductions

This directory contains small, standalone reproductions for public FunSearch, AlphaEvolve, and local TTT-Discover constructions requested in this thread.

- `cap_set_priority_function/`: FunSearch cap-set priority functions and explicit 512-cap construction.
- `kakeya_construction/`: AlphaEvolve finite-field Kakeya construction in `F_p^3`.
- `autocorrelation_autoconvolution/`: AlphaEvolve and TTT-Discover autocorrelation/autoconvolution sequence scoring.
